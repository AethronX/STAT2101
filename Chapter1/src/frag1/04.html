1 · Classify any variable in three questions

  1. Q1Category or number with arithmetic meaning? Category → qualitative (nominal or ordinal). Number → quantitative (interval or ratio). A number used only as a label (ID, zip code, jersey number) counts as a category.
  2. Q2If a category: does it have a natural order? No → nominal. Yes → ordinal.
  3. Q3If a number: counted or measured? Counted → discrete; measured → continuous. Then does zero mean "none"? Yes → ratio. No → interval.

4 · Ten traps

  1. Calling a numeric ID quantitative.
  2. Calling a sample percentage ("55% of those surveyed") inferential: it is descriptive.
  3. Putting year or °C at the ratio level.
  4. Treating letter grades as interval because they look like scores.
  5. Rounding k up in systematic sampling.
  1. Keeping a repeated or out-of-range number from Table D.
  2. Reading Table D in groups that don't match the number of digits in N.
  3. Swapping stratified and cluster: is it some from every group, or all from some groups?
  4. Calling convenience or volunteer samples random.
  5. Calling a defective instrument "sampling error": it is nonsampling error.
