What this means for how you study

Two of the outcomes are about interpretation (CLO3-B, CLO3-C), not calculation. Exam questions in this chapter rarely stop at "find the mean". They continue: which measure is more appropriate, and why? · which data set is more consistent? · what does this boxplot say about the shape? · what can be said about the number of observations in this interval? Every calculation in these files ends with a sentence of interpretation. Write that sentence in the exam too, because it carries marks.

The method rule for quartiles and percentiles

Hand methods, R and calculators can give different quartiles for the same data. On paper, use the course's procedure tables. In 3-3 and 3-4 you will see where R's summary() and quantile() disagree with them. If a question names a method ("using the percentile formula"), use that method.
