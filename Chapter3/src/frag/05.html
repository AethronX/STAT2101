3 · Fifteen traps that cost marks

  1. Finding the median or quartiles without ordering the data first.
  2. Dividing a sample variance by n, or a population variance by n − 1.
  3. Treating ΣX² as (ΣX)².
  4. Rounding deviations mid-calculation (the 2.335 vs 2.333 lesson).
  5. Writing "mode = 0" instead of "no mode".
  6. Computing a mean for a table with an open-ended class.
  7. Comparing raw SDs when the means or units differ; use the CV.
  8. Forgetting to take the √ when the question gives the variance.
  1. Writing "exactly 75%" for Chebyshev; it is at least. Round counts up for "at least".
  2. Using the empirical rule when the shape is not stated as bell-shaped.
  3. Percentile rank: counting values ≤ X instead of strictly below X, or forgetting + 0.5.
  4. c = n·p/100 with a decimal c: rounding to the nearest number instead of up.
  5. Including the median in both halves when n is odd (course method).
  6. Thinking a longer boxplot section holds more data; every section is 25%.
  7. "Adding a constant changes the SD": it does not. Multiplying changes the variance by c², not c.
