Part D · True / false with justification, and find the mistake

A one-word answer earns nothing. The justification is the mark.

True or false? Justify. If the standard deviation of a data set is 0, all its values are equal.

D2
3-1 CLO1-A · CLO3-C

True or false? Justify. The median is always one of the data values.

D3
3-2 CLO1-A · CLO3-C

True or false? Justify. Adding the same constant to every value changes the coefficient of variation.

D4
3-2 CLO1-A · CLO3-C

True or false? Justify. Chebyshev's theorem says exactly 75% of values lie within 2 SD of the mean.

D5
3-4 CLO1-A · CLO3-C

True or false? Justify. If Q₂ − Q₁ = Q₃ − Q₂, the distribution must be symmetric.

D6
3-3 CLO1-A · CLO3-C

True or false? Justify. The IQR can never be larger than the range.

D7
