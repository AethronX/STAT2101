Measures of Position مقاييس الموقع — الدرجة المعيارية والمئينات والربيعات والعشيرات والقيم الشاذة

Measures of position (location) give the relative position of a data value compared with the other values in a data set: standard scores (z), percentiles, deciles and quartiles. Both

1 · Standard scores (z-scores) Hadhrami

z-score: how many SDs a value lies above (+) or below (−) the mean

z = value − meanstandard deviation

sample: z = X − x̄s    population: z = X − μσ

z = 0: the value equals the mean. Rearranged: X = x̄ + z·s. If every value is converted to z, the new data have mean 0 and SD 1.

Ex 3-27 · Test scores

English 85 (mean 76, s = 4) and French 42 (mean 36, s = 3). Compare her relative positions.

zE = (85 − 76)/4 = 2.25   zF = (42 − 36)/3 = 2.00

Her relative position is higher in English.

Ex 3-28 · Marriage ages

Men: mean 26.4, s = 2; a man marries at 24. Women: mean 23.5, s = 2.3; a woman marries at 22.

zman = (24 − 26.4)/2 = −1.2   zwoman = (22 − 23.5)/2.3 ≈ −0.65

The woman's age at marriage is relatively higher: −0.65 is closer to her group's mean than −1.2 is to his.

الشرح بالعربي — الدرجة المعيارية zتقيس كم انحرافًا معياريًا تبعد القيمة عن المتوسط: z = (X − x̄)/s. الموجبة تعني فوق المتوسط، والسالبة تحته، والصفر يعني عند المتوسط تمامًا. فائدتها: مقارنة قيم من مجموعات مختلفة. درجة 85 في الإنجليزي لا تُقارن مباشرة بـ 42 في الفرنسي، لكن z = 2.25 أفضل من z = 2.00. انتبه مع الأرقام السالبة: −0.65 أكبر من −1.2، أي أفضل موقعًا.

2 · Percentiles Both

Percentiles divide ordered data into 100 equal parts, written P₁, P₂, …, P₉₉. The pth percentile Pₚ is the value that is greater than p% of the data values: p% lie below it and (100 − p)% above. P₁: 1% below. P₅₀ is the median. P₉₉: 99% below. There is no 100th percentile: a percentile counts the data below a value, and no value can be higher than the highest value in the data set, so percentiles run from 1 to 99. They are used in education and health (growth charts).

You are the 4th tallest of 20. 16 people are shorter than you: 16/20 × 100 = 80%, so you are at the 80th percentile, P₈₀. If your height is 1.85 m, then 80% of the group are shorter than 1.85 m. Amani

Percentile ≠ percentage Amani

A percentage measures your own score (40 out of 50 = 80%) and compares you with nobody. A percentile measures your position relative to others.

If 100 people sit a 50-question test and you get 40 right (80%), you don't know your percentile until you see the other scores. If all 99 others scored 60% or less, you beat 99% of the group: 99th percentile. It is quite possible to score 60% and be in the 95th percentile on a hard exam.

Case 1 · Percentile rank of a given value X

Percentile formula (order the data first)

Percentile of X = (number of values below X) + 0.5total number of values · 100

Activity · Jim's 78 Amani

20 scores: 34 37 48 59 62 75 76 78 79 80 82 85 90 91 92 92 94 97 99 100.

7 values are below 78: (7 + 0.5)/20 × 100 = 37.5th percentile. 37.5% of students scored lower than Jim.

Case 2 · The value at a given percentile p

Procedure: (1) order the data · (2) c = n·p/100

c = n · p100   (n = number of values, p = percentile)

3A: if c is not a whole number, round up to the next whole number and count up to that position. 3B: if c is a whole number, take the value halfway between the c-th and (c + 1)-th values.

Activity · Jim's class: P₅₀ and P₇₄ Amani

P₅₀: c = 20·50/100 = 10, a whole number, so (10th + 11th)/2 = (80 + 82)/2 = 81.

P₇₄: c = 20·74/100 = 14.8, not whole, so round up to 15. The 15th value = 92.

Ex 3-32, 3-33 · Traffic: P₆₅ and P₃₀ Hadhrami

P₆₅: c = 10·65/100 = 6.5, rounds up to 7. The 7th value = 20.

(2) لديك مئين وتريد قيمته ← احسب c = n·p/100. إذا كان c عشريًا قرّب لأعلى وخذ القيمة في ذلك الترتيب، وإذا كان صحيحًا خذ متوسط القيمتين c و c + 1. ولا تنسَ ترتيب البيانات أولًا.

3 · Quartiles Both

Quartiles divide ordered data into four equal groups: Q₁ = P₂₅, Q₂ = P₅₀ = median, Q₃ = P₇₅.

Method 1, medians (the textbook procedure table): order the data; Q₂ = the median; Q₁ = the median of the values below Q₂; Q₃ = the median of the values above Q₂. When n is odd, leave the median itself out of both halves.

Method 2, percentile formula: apply the Case 2 procedure with p = 25, 50, 75.

Activity · quartiles of Jim's class, both methods Amani

Method 1: n = 20 (even), so Q₂ = (80 + 82)/2 = 81. Lower ten: 34 … 80, Q₁ = (62 + 75)/2 = 68.5. Upper ten: 82 … 100, Q₃ = (92 + 92)/2 = 92.

Method 2: Q₁: c = 5, whole, so (5th + 6th)/2 = 68.5. Q₂: c = 10, giving 81. Q₃: c = 15, whole, so (15th + 16th)/2 = 92. Both methods agree.

Ex 3-34 · Traffic data (n = 10) Hadhrami

MD = (18 + 19)/2 = 18.5. Below: 9 12 15 16 18, so Q₁ = 15. Above: 19 20 22 24 25, so Q₃ = 22.

4 · Deciles and the summary of position measures Hadhrami

Deciles divide the distribution into 10 groups: D₁, …, D₉ correspond to P₁₀, …, P₉₀, and are found with the percentile formulas. The median = P₅₀ = Q₂ = D₅. Textbook Table 3-4 summarises all position measures.

5 · Interquartile range (IQR) Both

IQR: the range of the middle 50% of the data

IQR = Q₃ − Q₁

A rough measure of variability. Like the SD, the more variable the data, the larger the IQR. Unlike the SD, it hardly reacts to outliers.

Ex 3-35 · Traffic · Jim's class

Traffic: 22 − 15 = 7. Jim's class: 92 − 68.5 = 23.5.

6 · Outliers Both

An outlier is an extremely high or extremely low value compared with the rest of the data. Outliers strongly affect the mean and standard deviation; the median and IQR are much less affected.

Procedure for identifying outliers

(1) Order the data, find Q₁ and Q₃. (2) IQR = Q₃ − Q₁. (3) Compute 1.5 × IQR. (4) Lower fence Q₁ − 1.5·IQR; upper fence Q₃ + 1.5·IQR. (5) Any value below the lower fence or above the upper fence is an outlier.

Why outliers occur Amani: (1) measurement or observational error; (2) recording error, such as a value written or typed wrongly; (3) a rare value that is real but occurred by chance.

Ex 3-36 Hadhrami

5, 6, 12, 13, 15, 18, 22, 50

Q₁ = (6 + 12)/2 = 9, Q₃ = (18 + 22)/2 = 20, IQR = 11, 1.5·IQR = 16.5.

Fences: 9 − 16.5 = −7.5 and 20 + 16.5 = 36.5. Since 50 > 36.5, 50 is an outlier.

Activity · Jim's class Amani

1.5 × 23.5 = 35.25. Fences: 68.5 − 35.25 = 33.25 and 92 + 35.25 = 127.25. The smallest value, 34, is above 33.25: no outliers.

R for Lab Quiz I (outline CLO2-D): know why R can disagree with your paper answer

quantile(x, 0.25), summary(x) and IQR(x) use R's default method, which interpolates between positions. For Jim's 20 scores R gives Q₁ = 71.75 and Q₃ = 92 (IQR 20.25), not the 68.5 and 92 (IQR 23.5) from the procedure table. fivenum(x) uses Tukey's hinges, which match the course method when n is even but not always when n is odd. In a written exam always use the procedure tables. In the lab, report what R gives. Percentile rank has no single R function: (sum(x < 78) + 0.5)/length(x)*100 reproduces the formula.
