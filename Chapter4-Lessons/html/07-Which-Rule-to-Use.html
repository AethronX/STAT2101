Which rule do I use? كيف أختار القانون الصحيح خلال عشر ثوانٍ

Run this in order on every question. It takes ten seconds and it is the difference between a confident answer and a guess.

  1. Q1Does the question contain "not", "neither", "none", or "at least"?
    → Yes: use the complement, 1 − P(opposite). Compute the easy side. This check comes first because it can collapse the whole problem.
  2. Q2Does it say "given that", "if", "of those who", or state a fact as already settled?
    → Yes: conditional probability, P(B|A) = P(A∩B)/P(A). From a table, the condition's row or column total is the denominator.
  3. Q3Does it say "or"?
    → Addition rule. Then ask: can both happen together? No → P(A)+P(B). Yes → P(A)+P(B)−P(A∩B).
  4. Q4Does it say "and", or describe a sequence of stages?
    → Multiplication rule. Then ask: with replacement / separate devices? → independent, P(A)·P(B). Without replacement / "of those"? → dependent, P(A)·P(B|A).
  5. Q5Is the sample space too big to list?
    → Counting rules. Then ask: does order matter? Yes → nPr. No → nCr. Several categories combined → multiply them (Fundamental Counting Rule).
  6. Q6Is it asking for a probability after all that counting?
    → P(E) = n(E)/n(S). Count the event and the sample space with the same kind of rule — never mix a permutation numerator with a combination denominator.
خطوات اختيار القانون بالعربي — طبّقها بالترتيب
  1. هل في السؤال not / neither / none / at least؟ ← استخدم المتمّمة 1 − P(العكس).
  2. هل فيه given that / if / of those who، أو حقيقة وقعت مسبقًا؟ ← احتمال شرطي، والشرط في المقام.
  3. هل فيه or؟ ← قاعدة الجمع. هل يمكن وقوعهما معًا؟ لا ← اجمع. نعم ← اجمع واطرح التقاطع.
  4. هل فيه and أو مراحل متتالية؟ ← قاعدة الضرب. مع إرجاع ← اضرب مباشرة. بدون إرجاع ← الاحتمال الثاني يتغيّر.
  5. هل فضاء العينة أكبر من أن يُسرد؟ ← قواعد العدّ. الترتيب مهم ← nPr. غير مهم ← nCr. عدة فئات ← اضرب.
  6. هل المطلوب احتمال بعد العدّ؟ ← n(E) ÷ n(S)، بنفس نوع العدّ في البسط والمقام.
The one consistency rule that catches most §4-5 errors

Whatever you use for n(S), use for n(E). If the sample space counts unordered selections (combinations), the event must count unordered selections too. A numerator built from permutations over a denominator built from combinations is the most common wrong answer in the whole chapter, and it is always too large by a factor of r!.
