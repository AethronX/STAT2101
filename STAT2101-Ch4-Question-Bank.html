Part A — concept and definition questions A1–A25

A1← back

(b) an outcome

Definition: an outcome is the result of a single trial of a probability experiment. The sample space is the set of all outcomes.

A2← back

(c) the sample space

Denoted S; the number of elements in it is n(S).

A3← back

(b) a simple event

An event with two or more outcomes is a compound event.

A4← back

(c) certain

Probability rule (3). If P(E) = 0 the event is impossible — rule (2).

A5← back

(c) 5/4

Rule (1): 0 ≤ P(E) ≤ 1, and 5/4 = 1.25 > 1. Use this as a check on every answer you produce.

A6← back

(b) empirical

Empirical probability is based on observation: P(E) = f/n.

  2. (ii) Simple event — an event that consists of exactly one outcome. 1 mark

Method 1 — direct count: P(A ∪ B) = 1020 = 0.5

Method 2 — Addition Rule 2: P = 620 + 520 − 120 = 1020 = 0.5 ✔

7 green + 5 red = 12 sweets; without replacement → dependent.

  1. (a) P(GG) = 712·611 = 42132 = 722 ≈ 0.3182
  2. (b) One of each colour happens two ways — green then red, or red then green:
    P = 712·511 + 512·711 = 35132 + 35132 = 70132 = 3566 ≈ 0.5303
  3. (c) P(RR) = 512·411 = 20132 = 533 ≈ 0.1515

Verification: 42/132 + 70/132 + 20/132 = 132/132 = 1 ✔ The three cases are exhaustive, so they must sum to 1. Part (b) is where marks are lost — forgetting the second order halves the answer.

D6← back
  1. (a) P(test +) = 78/300 = 0.26
  2. (b) Condition "disease" → column total 60: P(+ | D) = 5760 = 0.95
  3. (c) Condition "test +" → row total 78: P(D | +) = 5778 = 1926 ≈ 0.7308
  4. (d) P(+ ∩ D) = 57/300 = 0.19; P(+)·P(D) = 0.26 × 0.20 = 0.052. Since 0.19 ≠ 0.052 → not independent (strongly dependent).

Why (b) ≠ (c): the test catches 95% of people who have the disease, but only 73% of positive results are true cases — because far more people are healthy than diseased. Reversing a conditional is not allowed; P(A|B) ≠ P(B|A), and this table shows exactly how far apart they can be.
