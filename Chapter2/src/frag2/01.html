Definitions Both · CLO2-B

A frequency distribution is the organization of raw data in table form, using classes and frequencies. A class is a category or interval in which each data value belongs to exactly one class (mutually exclusive). The frequency f is the number of data values that fall into that class.

1 · Categorical frequency distribution Both

Steps

(1) Make a table: Class · Tally · Frequency · Percent. (2) Tally the data. (3) Count the tallies to get f. (4) Percent = f/n × 100. (5) Check: Σf = n and the percents total about 100%. Then interpret the table in a sentence.

2 · Grouped frequency distribution Both

Procedure (number of classes is always given in this course; usually 5–20)

width = ⟪range‖number of classes⟫ = ⟪H − L‖k⟫ → always round UP to the next whole number (4.2 → 5, 4.8 → 5, 4.0 → 5)

(1) Number of classes k. (2) Width. (3) Starting point: the lowest value L (or a convenient number slightly less). (4) Lower limits: LCL₁ = min, each next LCL = previous LCL + width; each UCL = next LCL − 1. (5) Boundaries: LCB = LCL − ½ unit, UCB = UCL + ½ unit. (6) Tally and count. (7) Relative frequency f/n. (8) Check Σf = n and ΣRF ≈ 1.

Why a whole-number width still goes up (4.0 → 5)

With whole-number data, k classes of width w cover values from L to L + k·w − 1, and that must reach H. So k·w must be greater than the range. Range 28 with 7 classes gives exactly 4, and 7 × 4 = 28 classes would stop at L + 27, one short of H. That is why the rule says round up even from a whole number.

Important notes Amani

Classes must be continuous: a class with no data still appears, with f = 0. There must be enough classes to cover all the data. All classes have the same width. The width can be read from a table three ways: UCL − LCL + 1; the next LCL − this LCL; the next LCB − this LCB (= UCB − LCB).

4 · Relative, cumulative and cumulative relative frequency Both

Formulas

RF = ⟪f‖n⟫    CF = f₁ + f₂ + ⋯ (up to this class)    CRF = ⟪CF‖n⟫

RF can be a fraction, decimal or percent. CF counts the values less than or equal to a class's upper boundary. The first row ("less than the first LCB") is always 0; the last CF is n and the last CRF is 1 (100%). Example: frequencies 5, 8, 12 give a third-class CF of 5 + 8 + 12 = 25.
