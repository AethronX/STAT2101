How Chapter 2 is actually examined

Two kinds of mark. Construction (CLO2-B, C): build a grouped table (width, limits, boundaries, frequencies, RF, CF) and draw a correctly labelled graph. Reading (CLO3): given a table, histogram, ogive, bar, pie or stem-and-leaf, extract values and say something reasoned. Typical reads: "how many values are below 119.5?" from an ogive; "what is the class width?" from a table; "describe the shape" from a histogram; or "build the frequency table from this stacked bar graph", which is Dr. Amani's own activity. Every example here ends with that reading step, because the slides end each graph with "Interpret the graph".

The raw data printed in her notes has 79 values, but her frequency table uses n = 71 (19, 20, 16, 14, 0, 1, 1).Counting the printed grid gives 21, 22, 18, 16, 0, 1, 1 (n = 79). Lesson 2-1 builds the table from the raw data and shows both. The histogram and ogive examples (and her Chapter 3 calculations) use her n = 71 table.
