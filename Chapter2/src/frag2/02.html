1 · Histogram Both · CLO2-C

A histogram is a continuous bar graph showing the number of data items that fall within each interval. Bars must touch and be equally spaced.

Steps: (1) draw the x and y axes; (2) put the class boundaries on the x-axis and the frequency (or relative frequency) on the y-axis; (3) draw a bar for each class, spanning its boundaries, with height equal to its f (or RF); (4) title the graph and label both axes.

Marks for a correct graph (CLO3-A)

Title · labelled axes with units · boundaries (not limits) under the bars · bars touching · a jagged / broken line (zig-zag) on the x-axis when it does not start at 0 · empty classes left as gaps. Histograms are the main tool for judging the shape of a distribution (part 4).

2 · Frequency polygon Ahmed's slides · in the outline

Steps: (1) construct the frequency distribution; (2) draw and label the axes; (3) on the x-axis, mark the class midpoints (class marks); (4) plot each class's frequency as a point; (5) join neighbouring points with line segments; (6) add one class below the lowest and one above the highest, each with frequency 0, so the polygon touches the x-axis on both sides.

Midpoint (class mark)

Xₘ = ⟪LCL + UCL‖2⟫ = ⟪LCB + UCB‖2⟫    e.g. (100 + 104)/2 = 102

A relative frequency polygon is the same graph with RF on the y-axis. Example 2-7 (governors) has midpoints 45, 50, …, 75, RF 0.08, 0.08, 0.22, 0.28, 0.18, 0.10, 0.06, and extra end points at 40 and 80.

3 · Ogive (cumulative frequency graph) Both

An ogive is a line graph (not bars) of the cumulative frequencies of the classes. Steps: (1) draw both axes; (2) on the x-axis mark the first lower boundary and every upper boundary; (3) on the y-axis mark the cumulative frequencies; (4) label the axes; (5) plot each class's CF at its upper boundary; (6) join the points with straight lines; (7) start the line at 0 on the first lower boundary; (8) title it.

A cumulative relative frequency ogive is identical with CRF on the y-axis, so it ends at 1.

Reading an ogive (CLO3-B)

Go up from an x-value to the line, then across: that many values lie below it. From the temperature ogive, 41 states had a record below 119.5 °F, so 9 had 119.5 or more. The steepest segment is the class with the most data; a flat segment is an empty class. Governors (Example 2-7): CF 0, 4, 8, 19, 33, 42, 47, 50; CRF 0, 0.08, 0.16, 0.38, 0.66, 0.84, 0.94, 1.00, so 66% of governors were younger than 62.5.

4 · Distribution shapes Both · CLO3-B

Displaying data reveals its shape; the shape tells you the type of distribution, and knowing it is essential for choosing the right analysis (Chapter 3 uses it to choose between the mean and the median).
