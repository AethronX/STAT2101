Part D · True / false with justification

The justification is the mark.

D12-1 CLO2-B · CLO3-A

False. Classes must be continuous, so the empty class stays with f = 0.

D22-1 CLO2-B · CLO3-A

False. Round up even from a whole number, to 7. Otherwise the largest value falls outside the last class.

D32-2 CLO2-B · CLO3-A

False. Cumulative frequency never decreases. It is flat when a class is empty.

D42-2 CLO2-B · CLO3-A

False. A histogram shows quantitative classes on a number line with touching bars; a bar graph shows categories with separated bars.

D52-3 CLO2-B · CLO3-A

True. Every value can be read back from its stem and leaf, which a histogram cannot do.

D62-3 CLO2-B · CLO3-A

True. The parts must make up the whole circle.

D72-2 CLO2-B · CLO3-A

False. Every bar is divided by the same n, so only the y-scale changes.

D82-1 CLO2-B · CLO3-A

False. That gives 9 for the class 20.5–28.5, whose width is 8. Use UCB − LCB, or UCL − LCL + 1.
