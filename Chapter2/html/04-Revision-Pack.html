3 · Twelve traps

  1. Rounding the width to the nearest whole number instead of up.
  2. Leaving a whole-number width (4.0) unchanged.
  3. Putting class limits under histogram bars instead of boundaries.
  4. Leaving gaps between histogram bars, or no gaps in a bar graph.
  5. Deleting a class with f = 0.
  6. Plotting an ogive at midpoints or lower boundaries; it uses upper boundaries and starts at 0.
  1. Forgetting the extra empty class at both ends of a frequency polygon.
  2. Reading a stacked section as its top value instead of top − bottom.
  3. Pie angles that don't total 360° (check!).
  4. A stem-and-leaf plot with unordered leaves, a missing key, or a dropped empty stem.
  5. Naming skew after the peak instead of the tail.
  6. No title, unlabelled axes, or a missing zig-zag on an axis that doesn't start at 0.

4 · Removed this semester (recognise them only)

Pareto chart: a bar graph of a categorical variable with bars arranged from highest to lowest. Dot plot: each value plotted as a dot above a number line. Back-to-back stem-and-leaf: two data sets sharing one column of stems. Misleading graphs: a truncated y-axis or pictures scaled by area that exaggerate differences. These are marked "removed / not included" on the lecture slides and are absent from Dr. Amani's notes.
