4-3 · Independent vs dependent

  • Independent: A occurring does not change P(B). Dependent: it does.
  • With replacement, separate devices (coin + die), people from a large population → independent.
  • Without replacement, "of those who…", "of these…" → dependent / conditional.
  • Independent ≠ mutually exclusive. ME events with P > 0 are always dependent.
المستقلان: وقوع أحدهما لا يغيّر احتمال الآخر. السحب مع الإرجاع يعطي أحداثًا مستقلة، والسحب بدون إرجاع يعطي أحداثًا تابعة.

4-3 · Multiplication rules ("AND")

Rule 1 (independent): P(A ∩ B) = P(A) · P(B)

Rule 2 (dependent): P(A ∩ B) = P(A) · P(B | A) = P(B) · P(A | B)

n independent trials: P(all) = p · p ⋯ p = pⁿ

Without replacement, chain it: 2 aces = (4/52)(3/51) = 1/221; each next fraction drops by 1 on top (same kind) and bottom.

4-3 · Conditional probability

P(B | A) = P(A ∩ B) / P(A) P(A) ≠ 0

The condition goes in the denominator. "Given that", "if", "of those who", or a fact stated as already true ("he has to park in a no-parking zone").

Independence tests (any one): P(B | A) = P(B) · P(A | B) = P(A) · P(A ∩ B) = P(A)P(B)

4-3 · Tree diagrams

Multiply along a branch (P of a path) · add across the paths that give the event · branches from each point sum to 1 · all end paths sum to 1.

P(B) = P(A)·P(B | A) + P(Aᶜ)·P(B | Aᶜ)

Reverse question: P(A | B) = P(A ∩ B) / P(B)

4-3 · "At least one"

P(at least one) = 1 − P(none)

n independent tries, success p: 1 − (1 − p)ⁿ. Die 3 rolls, at least one 5: 1 − (5/6)³ = 91/216.

4-4 · Fundamental counting rule

k₁ × k₂ × ⋯ × kₙ
  • Repetition allowed: same count each slot (10 × 10 × 10 × 10).
  • Not allowed: drop by 1 each slot (10 × 9 × 8 × 7).
  • Restricted slot first (first digit ≠ 0: 9 × 9 × 8 × 7).
  • and → × · or → + (cases)

4-4 · Permutations (order matters)

Rule 1: ₙPᵣ = n! / (n − r)! ₙPₙ = n!

Rule 2 (identical objects): n! / (r₁! r₂! ⋯ rₚ!)

STATISTICS: 10!/(3! 3! 2!) = 50,400 · LEVEL: 5!/(2! 2!) = 30. Tally the letters first; the counts must sum to n.

4-4 · Combinations (order doesn't matter)

ₙCᵣ = n! / [(n − r)! · r!] = ₙPᵣ / r!

ₙCᵣ = ₙCₙ₋ᵣ · ₙC₀ = ₙCₙ = 1 · ₙC₁ = n · C ≤ P always.

Two groups: 3 of 7 women and 2 of 5 men = ₇C₃ × ₅C₂ = 35 × 10 = 350.

Must include a person: fix them, then ₙ₋₁Cᵣ₋₁. Must exclude: ₙ₋₁Cᵣ.

4-5 · Probability with counting rules

  1. n(S): all ways to select (usually ₙCᵣ).
  2. n(E): ways that meet the condition (product of C's, one per group).
  3. P(E) = n(E) / n(S), then a sentence.
P(k from group a, r − k from group b) = ₐCₖ · ᵦCᵣ₋ₖ / ₐ₊ᵦCᵣ

Defective: 24 circuits, 4 bad, pick 4. P(exactly 2 bad) = ₄C₂·₂₀C₂/₂₄C₄ = 1140/10626 ≈ 0.1073. P(at least 1 bad) = 1 − ₂₀C₄/₂₄C₄ ≈ 0.5440.

Count n(E) and n(S) with the same rule. The C-method equals the without-replacement chain: ₉C₃/₁₂C₃ = (9/12)(8/11)(7/10).

احسب فضاء العينة ثم الحدث بنفس طريقة العدّ، ثم اقسم. «على الأقل واحد» = 1 − الكل من المجموعة الأخرى.

Traps that cost marks

  1. Missing "without replacement": the second denominator must drop.
  2. Putting P(B) under P(A ∩ B) when the question asks for P(B | A).
  3. Treating "of those who…" as an unconditional probability.
  4. Calling ME events independent.
  5. Counting only one order in "one of each" (×2 in the chain method).
  6. Permutation for a committee, or a combination for officers.
  7. Adding instead of multiplying across groups.
  8. 0! = 0 (it is 1); forgetting the repeated letters in rule 2.
  9. A permutation numerator over a combination denominator.

Write it like a marker reads

  1. Define events; say "with" or "without replacement".
  2. Name the rule: "dependent, so Rule 2"; "order doesn't matter, so ₙCᵣ".
  3. Show n(E) and n(S) separately, then divide.
  4. Simplify, give a decimal, check 0 ≤ P ≤ 1.
