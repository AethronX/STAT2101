4-1 · Key terms (define as sentences)

  • Probability experiment: a chance process with well-defined results (outcomes).
  • Outcome: the result of a single trial.
  • Sample space S: the set of all possible outcomes; size n(S).
  • Event: a set of outcomes (a subset of S).
  • Simple event = 1 outcome · compound = 2 or more.

4-1 · Probability rules

  1. 0 ≤ P(E) ≤ 1 (negative or > 1 means an error)
  2. P(E) = 0 → E is impossible (a 9 on one die)
  3. P(E) = 1 → E is certain (a number < 7 on one die)
  4. The probabilities of all outcomes in S add to 1

Scale: 0 impossible · 0.25 unlikely · 0.5 50–50 · 0.75 likely · 1 certain

4-1 · Complement

P(Ē) = 1 − P(E) · P(E) + P(Ē) = 1

Ē = everything in S that is not in E (stay inside S!). Use it for: not · none · neither · at least one.

P(at least one) = 1 − P(none)

4-1 · Set operations (Venn)

  • A ∪ B "A or B": in A, in B, or both (inclusive)
  • A ∩ B "A and B": in both
  • Ā = Aᶜ "not A": in S but not in A
  • Check: n(A ∪ B) + n((A ∪ B)ᶜ) = n(S)

4-2 · Mutually exclusive (disjoint)

A and B cannot occur at the same time: no common outcomes.

A ∩ B = ∅ ⇔ P(A ∩ B) = 0

Write the intersection, then decide. Die: even {2,4,6} & odd {1,3,5} → ME. Even & {1,2,4} share {2,4} → not ME.

If P(A) + P(B) > 1, A and B cannot be ME.

المتنافيان لا يقعان معًا (لا تقاطع بينهما). اكتب التقاطع أولًا ثم احكم.

4-2 · Addition rules ("OR")

Rule 1 (ME): P(A ∪ B) = P(A) + P(B)

Rule 2 (not ME, always safe): P(A ∪ B) = P(A) + P(B) − P(A ∩ B)

Rearranged: P(A ∩ B) = P(A) + P(B) − P(A ∪ B)

3 ME events: P(A∪B∪C) = P(A)+P(B)+P(C)

3 events, general:

P(A∪B∪C) = ΣP(single) − [P(A∩B)+P(A∩C)+P(B∩C)] + P(A∩B∩C) «أو» = جمع. إذا كان بينهما تداخل نطرح التقاطع مرة لأنه حُسب مرتين.

Traps that cost marks

  1. "or" read as exclusive: it means or both.
  2. Rule 1 used when events overlap: double counts (king or heart = 16/52, not 17/52).
  3. Multiplying instead of adding for ME events: P(A∪B) = P(A)+P(B), and P(A∩B) = 0.
  4. Unequal outcomes treated as equally likely ({2 heads, 1 head, 0 heads} is wrong; use HH, HT, TH, TT).
  5. 11 dice sums are not equally likely: always divide by 36.
  6. "at least 2" ≠ "exactly 2"; "at most" includes the number.
  7. Ā forgetting elements of S that lie in B.
  8. Empirical: dividing by the wrong total; check Σf = n.

  2. Write S and E in set notation (the lecturer requires it).
  3. Name the rule: "not ME, so Rule 2".
  4. Substitute, simplify the fraction, give a decimal.
  5. Check 0 ≤ P ≤ 1 and that complements add to 1.
